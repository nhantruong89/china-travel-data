# China Travel — offline city data

Offline data packs (map + places to eat, see and stay) for the China Travel iPhone app.

- Packs and `catalog.json` are published on the [`packs` release](../../releases/tag/packs).
- **Add a city:** copy a file in `cities/`, change the names and `bbox`, open a pull request. GitHub Actions builds and validates the pack; when merged it is published and appears in the app automatically.
- Packs are rebuilt monthly from fresh OpenStreetMap data.

## Thêm thành phố
Sao chép một file trong `cities/`, đổi tên và `bbox`, mở pull request. GitHub tự dựng và kiểm tra gói; gộp vào là gói được đăng và tự hiện trong app.
